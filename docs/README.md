# Mission authority and evidence

This documentation index is the portable guidance entry point. The linked
product contracts remain authoritative; this index does not duplicate their
schemas, install a provider or grant execution authority.

## Intent authority

[intent-authority.md](intent-authority.md) owns immutable requester intent,
receipt-confirmed baseline/amendment operations and CLI/MCP examples.

## Provider evidence

[provider-evidence.md](provider-evidence.md) owns preflight, completion and
handover admission, diagnostics, fixture boundaries and the unavailable
production adapter.

## Validation features

Use the [exact feature-qualified commands](provider-evidence.md#validation-features).
Fixture success proves admission only, not production runtime readiness.
